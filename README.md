## Open-source

Documents, admin panels and the plumbing around them. Every package ships an
English README with German, Russian and Chinese translations under `docs/`, a
changelog, and CI across the supported version matrix.

### Documents

| Package | What it does |
| --- | --- |
| [php-pdf](https://github.com/dskripchenko/php-pdf) | Pure-PHP, MIT-licensed PDF toolkit — generate, read, merge. Charts, barcodes, AcroForm, PDF/A, encryption, PKCS#7 signing. |
| [php-docx](https://github.com/dskripchenko/php-docx) | Zero-dependency DOCX ⇄ HTML engine, validated against the ECMA-376 schemas on every push. |
| [laravel-php-pdf](https://github.com/dskripchenko/laravel-php-pdf) · [laravel-php-docx](https://github.com/dskripchenko/laravel-php-docx) | Laravel bridges for both — Blade views straight to PDF or Word. |
| [php-docx-phpword](https://github.com/dskripchenko/php-docx-phpword) | The HTML layer PHPWord pipelines are missing. |
| [php-pdf-fonts-liberation](https://github.com/dskripchenko/php-pdf-fonts-liberation) | Metric-compatible font bundle, kept apart so the OFL zone stays out of the MIT one. |
